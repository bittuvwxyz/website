**Website** is an open-source project focused on building a modern, scalable, and maintainable website using **PHP**, **HTML**, **CSS**, and **JavaScript**.

The project starts small and grows step by step with the help of the open-source community. Every contribution, whether it's fixing a typo or adding a new feature, is welcome.
